# CSET343 --- AI in Healthcare

## Course Overview

This repository contains the laboratory work, practical implementations,
and daily coursework for **CSET343 --- AI in Healthcare**.

The repository is maintained as a collection of course-related exercises
and assignments completed throughout the semester. Each practical
demonstrates concepts related to artificial intelligence, machine
learning, data processing, and their applications in healthcare.
